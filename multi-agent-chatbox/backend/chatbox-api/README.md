# Multi-Agent Chatbox API

Backend API service for the multi-agent chatbox application using DeepSeek API.

## Features
- Multi-agent conversation management
- Dynamic agent personalities
- Configurable conversation rounds
- Automatic conversation progression
- Final summary generation

## Environment Variables
- DEEPSEEK_API_KEY: API key for DeepSeek service
- DEEPSEEK_API_BASE: Base URL for DeepSeek API
